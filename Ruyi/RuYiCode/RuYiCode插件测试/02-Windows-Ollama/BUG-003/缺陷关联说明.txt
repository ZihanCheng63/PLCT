BUG-003 关联说明

BUG-003 是 Windows 11 环境下首次记录的 Ollama 插件连接缺陷。
同一现象已在 Ubuntu 24.04.5 LTS 环境
以 BUG-004 独立复现。

BUG-003：Windows 首次记录（插件连接 Ollama 返回 HTTP 404）。
BUG-004：Ubuntu 独立复现，表现完全一致。

两次复现配置与表现均一致（同插件版本、同 Ollama 版本、同模型、
同 Endpoint），均表现为 Ollama 服务侧 /v1/models 返回 200
而插件返回 404。

结论：BUG-003 与 BUG-004 为同一跨平台缺陷。
汇总时按 1 个唯一缺陷、2 次跨平台复现统计；
两个证据目录分别保留，不合并原始截图、日志和配置。
